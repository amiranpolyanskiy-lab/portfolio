# Сайт-портфолио Амирана Полянского

Статический сайт (HTML/CSS/JS без сборки). Репозиторий: `amiranpolyanskiy-lab/portfolio`, ветка `main`.
Публикация: GitHub Pages, домен `amiranpolyanskiu-ux-ui.ru` (файл `CNAME`), DNS на Cloudflare.
Описание продукта и позиционирования — в `PRODUCT.md`.

## Правила работы
- Не менять тексты и вёрстку без явной просьбы. Смежные находки озвучивать, но не трогать.
- Сайт-референс открывать в браузере и смотреть глазами, а не читать текстовую выжимку.

## Устройство сайта
- `index.html` — главная. Страницы кейсов: `case-*.dc.html`. Рендерит их `support.js`.
- Сайт только в тёмной теме: её включает `initTheme()` в `index.html`. Он же подменяет логотипы в `#cases` на `*-dark.svg`.
- Кнопки почты (Telegram и mailto) в блоках `#about` и `#contacts`. Кнопки почты обёрнуты в `<!--email_off-->`, как страховка на случай, если Cloudflare снова включат как прокси (он подменяет адрес на `[email protected]`).

## Не ломать
- Cloudflare используется только как DNS: на всех записях сайта оставлять серое облачко («DNS only»), проксирование не включать. С проксированием большие файлы (больше ~23 КБ) обрываются, картинки не грузятся, а продление сертификата GitHub ломается. HTTPS выпускает и продлевает сам GitHub Pages (Enforce HTTPS включён).
- Файлы сайта приходят экспортом из Claude Design. После нового экспорта проверить кнопки почты в `index.html` (блоки `#about` и `#contacts`): они должны быть в `<!--email_off-->…<!--/email_off-->`. Если нет, вернуть.

- React лежит локально в `vendor/` (раньше `support.js` грузил его с `unpkg.com`, при сбое страница не собиралась). В `support.js` строки с `REACT_URL` и `REACT_DOM_URL` указывают на `vendor/…`. В `antigravity.js` добавлена страховка перезапуска частиц (`setInterval` в конце файла). После нового экспорта из Claude Design эти правки пропадут, нужно вернуть.
- Для локальной проверки нужен сервер: `npx -y serve -l 8001 .` в папке проекта (по `file://` страница пустая).

## История проблемы (решена 2026-10-14)
Через проксирование Cloudflare большие файлы обрывались на ~23 КБ: картинки не грузились, а тема оставалась светлой (тёмную включает скрипт после полной загрузки). После перевода записей на «DNS only» и выпуска сертификата GitHub Pages сайт грузится целиком. Переезд на другой хостинг не нужен.
