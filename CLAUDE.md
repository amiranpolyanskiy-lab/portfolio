# Сайт-портфолио Амирана Полянского

Статический сайт (HTML/CSS/JS без сборки). Репозиторий: `amiranpolyanskiy-lab/portfolio`, ветка `main`.
Публикация: GitHub Pages, домен `amiranpolyanskiu-ux-ui.ru` (файл `CNAME`), DNS на Cloudflare.
Описание продукта и позиционирования — в `PRODUCT.md`. Концепты дизайна — в `concepts/`.

## Правила работы
- Не менять тексты и вёрстку без явной просьбы. Смежные находки озвучивать, но не трогать.
- Сайт-референс открывать в браузере и смотреть глазами, а не читать текстовую выжимку.

## Устройство сайта
- `index.html` — главная. Страницы кейсов: `case-*.dc.html`. Рендерит их `support.js`.
- Сайт только в тёмной теме: её включает `initTheme()` в `index.html`. Он же подменяет логотипы в `#cases` на `*-dark.svg`.
- Кнопки почты (Telegram и mailto) в блоках `#about` и `#contacts`. Кнопки почты обёрнуты в `<!--email_off-->`, чтобы Cloudflare не подменял адрес на `[email protected]`. Не убирать.

## Не ломать
- Не отключать проксирование Cloudflare (оранжевое облачко): GitHub Pages не выпускал HTTPS-сертификат для домена, сертификат даёт Cloudflare. Почтовые записи DNS остаются «DNS only».
- Файлы сайта приходят экспортом из Claude Design. После нового экспорта проверить кнопки почты в `index.html` (блоки `#about` и `#contacts`): они должны быть в `<!--email_off-->…<!--/email_off-->`. Если нет, вернуть.

## Известная проблема (на 2026-10-13)
Большие файлы с сайта обрываются на ~23 КБ: картинки не грузятся, страница остаётся в состоянии загрузки, тема светлая. Файлы на сервере целые. Подозрение: фильтрация трафика к зарубежному хостингу. Проверка: открыть сайт через VPN. Рассматривается перенос на российский хостинг (Beget, Timeweb).
