# Портфолио — полный экспорт

Все файлы лендинга: главная, 7 кейсов, шрифты, картинки, видео, скрипты. Сборка не нужна.

## Структура

- `index.html` — главная (герой, кейсы, опыт, навыки, контакты)
- `case-hostme.dc.html` — редизайн системы управления рестораном
- `case-design-system.dc.html` — дизайн-система с нуля
- `case-receipts.dc.html` — автоотправка чеков для самозанятых
- `case-refunds.dc.html` — отложенные возвраты платежей
- `case-subscriptions.dc.html` — продукт «Подписки»
- `case-help.dc.html` — редизайн главной страницы помощи
- `case-contactme.dc.html` — конструктор мини-сайтов
- `support.js` — рантайм, который рендерит страницы (нужен всем файлам)
- `antigravity.js` — фон с точками, отталкивающимися от курсора (главная)
- `fonts/` Gilroy · `logos/` SVG-логотипы · `photo/` скриншоты и рендеры · `video/` видео

## Запуск

Нужен локальный сервер — по `file://` страницы не запустятся.

```bash
cd <папка с этими файлами>
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Как устроен код

- Каждая страница — один самодостаточный HTML: разметка внутри `<x-dc>`, логика в классе `Component` в конце файла.
- `support.js` собирает из этого React-дерево в браузере (React тянется с unpkg — нужен интернет).
- Стили инлайновые в `style="..."`; в `<helmet><style>` только шрифты, ресеты, тёмная тема и ховеры.
- Тёмная тема — атрибут `data-theme="dark"` на корне + переопределения по цветам; переключатель в шапке, состояние в `localStorage`.
- Интерактив внутри кейсов (сравнение до/после, переключатели состояний карточки, зум скриншотов, раскрытие блоков исследования) живёт в классе `Component`.

## Токены

- подложки `#F5F8FA`, `#efefef`, `#E8EDF2`
- акцент `#2c5cf0`, светлый акцент `#E6EBFF`, служебный синий `#6d86ea`
- радиусы 12 / 14 / 26 / 28 / 32 px, пилюли `100px`
- Gilroy 400–800, размеры через `clamp()`

## Деплой как есть

Любой статический хостинг (GitHub Pages, Netlify, Vercel, Cloudflare Pages) — заливается папка целиком.

## Если переносить в фреймворк (Next / Astro / Vite)

Просьба к Claude Code примерно такая: «перенеси эти страницы на Astro, разметку из `<x-dc>` в компоненты, логику из класса `Component` в клиентские скрипты, `support.js` убрать».

Что стоит учесть:
1. Общий `<style>` почти идентичен во всех файлах — вынести в один CSS.
2. Повторяющиеся блоки (шапка, «Следующий кейс», плашка метрик, шаг сценария, карточка «Результаты») — в компоненты.
3. Инлайн-стили можно оставить или перевести в CSS-модули / Tailwind.
4. Тёмная тема и `localStorage` — в один общий скрипт.
